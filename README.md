# Autonomous Multi-Agent RCA Swarm using Valkey as a Shared Blackboard

This project demonstrates an **Autonomous Multi-Agent Root Cause Analysis (RCA) Swarm** where specialized AI agents coordinate stigmergically through an in-memory blackboard powered by **Valkey** (or Google Cloud Memorystore for Valkey).

---

## 🎯 Architectural Highlights & Valkey Primitives

| Primitive | Valkey Key Pattern | Role & Agentic Behavior |
| :--- | :--- | :--- |
| **Valkey Streams** | `stream:rca:events` | Event log for stigmergic handoffs across agents using consumer groups (`XREADGROUP`, `XACK`, `XAUTOCLAIM`). |
| **Sorted Set** | `rca:timeline` | Chronological microservice anomalies scored by epoch millisecond timestamp. |
| **Hashes** | `rca:hypotheses` | Persistent store for structured hypothesis records mapped by `hypothesis_id`. |
| **Sorted Set** | `rca:confidence` | Hypothesis leaderboard dynamically sorted by confidence score (-100 to 100) via `ZINCRBY`. |
| **Sets** | `rca:hypothesis:<id>:contributors` | Unique agent contributor tracking to prevent echo-chamber confidence inflation. |
| **Strings (Distributed Locks)** | `lock:investigate:<service>:<scope>` | Single-flight distributed locks (`SET NX EX`) with Lua verification to prevent duplicate telemetry queries. |
| **Pub/Sub** | `rca:control:broadcast` | Broadcast interrupt bus for immediate swarm termination upon consensus. |
| **String** | `rca:final_verdict` | Final post-mortem RCA report generated by the Synthesizer daemon. |

## 🐝 Specialized Agent Swarm Roster

1. **`TraceExplorerAgent`**:
   - *Domain:* Distributed traces, ingress spans, cascade latencies.
   - *Action:* Reacts to `ALERT_INGRESS_TIMEOUT`, inspects root spans, identifies `auth-api` 504 bottleneck, records anomalies to `rca:timeline`, and proposes `H_AUTH_POOL_EXHAUSTION` (Confidence: 50).
2. **`DatabaseSleuthAgent`**:
   - *Domain:* Postgres connection pools, slow queries, row locks.
   - *Action:* Audits DB telemetry. Notices queries are fast (<2ms p99) and 0 locks exist, refuting direct DB lock theory (`ZINCRBY rca:confidence -40`), attributing pool starvation to caller query storm.
3. **`DeployScoutAgent`**:
   - *Domain:* Git commits, CI/CD deploys, feature flag flips.
   - *Action:* Discovers recent commit `4e81a0d8` that reduced cache TTL to 0. Branches root-cause hypothesis `H_CACHE_TTL_ZERO` from `H_AUTH_POOL_EXHAUSTION` and seeds score to 60.
4. **`InfraK8sAgent`**:
   - *Domain:* Kubernetes pods, OOMKills, node CPU/Memory pressure.
   - *Action:* Audits pod health, rules out container resource exhaustion, and corroborates `H_CACHE_TTL_ZERO` (+30 -> 90 pts), reaching consensus with $\ge 2$ contributors.
5. **`SynthesizerArbiter` (Daemon)**:
   - *Domain:* Session supervisor and convergence sentinel.
   - *Action:* Monitors confidence $\ge 85$ and $\ge 2$ contributors. Emits `TERMINATE` over Pub/Sub, writes final post-mortem report to `rca:final_verdict`, and displays the executive summary.

## 🚀 Quickstart & Running the Demo

### Prerequisites
- Docker (to run local Valkey container)
- Python 3.10+

### Option 1: One-Click Execution
```bash
./test_demo.sh
```

### Option 2: Step-by-Step Execution

1. **Start Valkey Container:**
```bash
docker run -d --name valkey-local -p 6379:6379 valkey/valkey:latest valkey-server --save "" --appendonly no
```

2. **Install Python Dependencies:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. **Run Unit Tests:**
```bash
python3 -m unittest discover -s tests -p "test_*.py"
```

4. **Initialize Harness & Reset Keys:**
```bash
python3 harness_setup.py
```

5. **Launch Swarm with Incident Injection:**
```bash
python3 agent_swarm.py --trigger-incident
```

## ☁️ Connecting to Google Cloud Memorystore for Valkey

To run this demo against a managed Cloud Memorystore for Valkey instance:
```bash
export REDIS_HOST="<MEMORYSTORE_VALKEY_PSC_IP>"
export REDIS_PORT="6379"
export REDIS_PASSWORD="<OPTIONAL_AUTH_STRING>"

./test_demo.sh
```
All client connections in `blackboard.py` automatically read these environment variables.
